# Battery-Foiling-Machine
It is a machine used to foil IPS batteries. The machine was not functional for more than a year. I had to troubleshot the sensor related issues, change circuit diagram, reprogrammed the PLC, and replaced the VFD with a new one in order to make the machine running.
[!Watch the Video](https://shields.io)]([https://drive.google.com/file/d/10dCL7EV78jeOO3XaB7-1wEQLlRn2Xsbe/view?usp=sharing])
Here, I have used Shihlin PLC, Mitsubishi VFD, and different positional and proximity sensors to build this project.
